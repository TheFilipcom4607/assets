Prusament → Bambu Studio (X2D)

Pick a Prusament filament. Its PrusaSlicer profile (Core One) is downloaded from Prusa's GitHub, converted, and saved as a Bambu Studio filament preset for the Bambu Lab X2D, 0.4 nozzle.

    Loading profiles…
    1. Click a filament; a .json file downloads.
    2. Bambu Studio: Go to the main home tab, not prepare, then File → Import → Import Configs…
    3. It appears under the filament list → Custom.
    Unofficial; not affiliated with Prusa Research or Bambu Lab. Temperatures, bed temps, density and cost come from Prusa's profile; fan, flow and speed come from Bambu's matching X2D profile (needs Bambu Studio's X2D profiles installed). Materials with no Bambu equivalent (e.g. PVB) use PLA as a base, so test-print before trusting them.
