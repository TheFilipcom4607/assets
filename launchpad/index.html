Connection help & hardware notes

Safari won't connect. Use current Chrome or Edge. This is a local, self-contained page: no accounts, libraries, or network requests. Your personal bests are stored only in this browser.

If MIDI is blocked for a local file, serve this folder from Terminal with python3 -m http.server 8000 --bind 127.0.0.1, then open http://localhost:8000/launchpad-arcade.html in Chrome. Web MIDI requires a trusted context such as localhost or HTTPS. Allow MIDI / SysEx in the browser's site settings if you previously denied it.

No device listed? Check the cable supports data, not only charging. Unplug and reconnect; close other MIDI apps. The selectors list connected Launchpad MIDI ports, not DAW ports. If you have multiple Launchpads, select matching input and output, then connect. Reconnect explicitly after unplugging.

Done playing? Click Disconnect & restore to clear LEDs and return modern Launchpads to Live Mode. Older models receive an all-off frame. Closing a tab attempts same, but browsers cannot guarantee MIDI delivery during shutdown.

Games pause when this tab becomes hidden or controller disconnects. Keep this tab visible while playing on hardware. Tetris uses compact 8×8 board, seven tetrominoes, clockwise rotation with simple wall kicks, and dim landing preview. It is not full-size tournament-rules implementation.

Modern Launchpads use Novation's Programmer Mode MIDI/SysEx surface. Older models use standard Web MIDI messages.
